🛡️ Configurações — Site Seguro?

Opcionalmente, você pode adicionar sua própria chave da API do Google Safe Browsing. Com a chave configurada, toda vez que você abrir o popup a extensão consulta em tempo real a base de ameaças conhecidas do Google (phishing, malware e software indesejado) além das heurísticas locais — se o site estiver na lista, a pontuação cai imediatamente para 0. A chave é gratuita e pode ser obtida no Google Cloud Console. Sem ela, a extensão continua funcionando normalmente usando apenas as heurísticas locais.
